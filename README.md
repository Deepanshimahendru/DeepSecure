# DeepSecure 🔐

DeepSecure is a simple Python-based file encryption and decryption tool built with a clean GUI interface. The project allows users to securely encrypt and decrypt files using password-based protection.

## Features

* Encrypt files securely
* Decrypt encrypted files
* Password protection support
* Simple and beginner-friendly GUI
* Fast and lightweight

## Technologies Used

* Python
* Tkinter
* Cryptography Library

## Project Structure

```bash
DeepSecure/
│
├── app.py
├── assets/
├── encrypted_files/
├── decrypted_files/
├── requirements.txt
└── README.md
```

## Installation

Clone the repository:

```bash
git clone https://github.com/Deepanshimahendru/DeepSecure.git
```

Move into the project folder:

```bash
cd DeepSecure
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python app.py
```

## How It Works

1. Select a file
2. Enter a password
3. Choose Encrypt or Decrypt
4. The processed file gets saved securely
